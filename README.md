# Полевая платформа

Офлайн-приложение для полевых работ в карьере (планшет на Windows). Работает без интернета: данные приходят файлом-пакетом из основной платформы мониторинга и хранятся только на устройстве.

> В репозитории только код приложения. Данных компании, паролей и ключей здесь нет и быть не должно: полевые пакеты (`*.gfield`) исключены через `.gitignore`.

## Как это работает

1. **Подготовка** — в основной платформе страница «Подготовка к полевым работам»: выбор схемы (рельеф), разломов и слоёв → «Собрать и скачать пакет» (файл `.gfield`, по желанию защищён паролем).
2. **Перенос** пакета на планшет любым способом (USB, облако, почта).
3. **Полевая работа** — «Начать полевую работу» → импорт пакета → вкладки «Карта», «Список точек», «Модель», «Записи», «Пакет». Новые точки, замеры и выходы воды фиксируются кнопкой «Записать» (касанием по плану или по рельефу в 3D). Всё работает без сети.
4. **Возврат** — экспорт результатов и загрузка в основную платформу (этап 3 разработки).

## Состояние

| Этап | Содержание | Статус |
|---|---|---|
| 1 | Формат пакета и экспорт в основной платформе; импорт, карта, список точек, план модели, слои, офлайн-кэш | сделан |
| 2 | 3D-вид модели с вращением; фиксация точек водопроявлений и выходов воды, замеры дебита (числом и объёмным методом), фото | сделан (записи хранятся только на планшете) |
| 2.1 | Настройки слоёв: точки интереса и состояние на дату, разломы (выбор, цвет, прозрачность), рельеф 3D (окраска по карте схемы / слоям / глубине, изолинии с отметками); график дебита; правка точек пакета | сделан |
| 3 | Экспорт результатов, импорт в основную платформу с предпросмотром и подтверждением | в плане |
| 4 | GPS и калибровка по контрольным точкам | отложен |

## Запуск для разработки

```bash
node dev-server.js 8940   # http://localhost:8940
```

Без сборки: ES-модули, `htm` + React с CDN (importmap в `index.html`). Service Worker (`sw.js`) на localhost включается только с `?sw=1`, на HTTPS — всегда.

## Установка на планшет

Один раз открыть адрес приложения в Edge **с интернетом** → меню «Приложения → Установить этот сайт как приложение». Первый запуск сохраняет код и библиотеки в офлайн-кэш; дальше приложение открывается без сети. Данные полевой работы лежат в IndexedDB устройства.

См. также `docs/ARCHITECTURE.md` (формат пакета, устройство приложения).
