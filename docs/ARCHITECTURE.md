# Устройство и формат пакета

## Приложение

- `src/App.js` — оболочка и вкладки; `src/pages/*` — вкладки («Карта» и «Модель» — один компонент `PlanPage` с разной подложкой).
- `src/components/PlanCanvas.js` — план на canvas: масштаб колёсиком и щипком, сдвиг пальцем, выбор касанием (Pointer Events).
- `src/lib/plan-draw.js` — слои плана в мировых координатах (X — восток, Y — север).
- `src/lib/session.js` — чтение пакета, сохранение в IndexedDB (`src/store.js`), разбор рельефа и разломов.
- `sw.js` — офлайн-кэш (кэш сначала, обновление в фоне).

## Пакет `.gfield`

ZIP (deflate; JPEG/PNG — без сжатия). Если задан пароль — файл целиком зашифрован: `GFE1` | соль 16 | вектор 12 | AES-GCM-256 (ключ — PBKDF2-SHA256, 200 000 итераций). Незашифрованный пакет начинается с `PK`.

| Файл | Содержимое |
|---|---|
| `manifest.json` | `format: "gfield"`, `version`, карьер, неделя схемы, границы карты, дата и автор, состав (`counts`) |
| `data.json` | `points` (замеры и выходы воды: `kind = "outflow"`, `parent_number`), `piezo`, `observation`, `horizontal`, `domains`, `faults2d`, `faultProps` |
| `terrain.bin` | рельеф (TIN): `GT3D` + JSON + Float32 x/y/z относительно `origin` + Uint32 треугольники + Uint8 тип рельефа |
| `faults.bin` | выбранные поверхности разломов (`PF3D`, как в основной платформе) |
| `map.jpg` / `map.png` | подложка вкладки «Карта» |

Читатель отвергает пакеты с `version` новее поддерживаемой и просит обновить приложение.

## Общие модули с основной платформой

`zip-pack.js`, `field-crypto.js`, `field-formats.js`, `terrain-sampler.js` — одинаковые файлы в обоих проектах (формат обязан совпадать). При изменении формата менять оба и поднимать `version`.
